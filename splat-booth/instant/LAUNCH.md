|---|---|---|
| Game | `splat-booth-instant.zip` | Instant Games → Web Hosting |

Use these if the form asks you to describe yourself and the game:

- **Developer:** Independent developer, first Instant Game.

- **Target audience:** Teens and adults (13+) looking for quick, light-hearted stress relief with friends.

## Review notes (paste into "Notes for reviewers" if there is one)
> Splat Booth is a light-hearted slapstick game. Players may load a photo, which is only drawn on their device and never uploaded, stored or shared; the shared score card never includes the photo. The game shows a reminder to use only faces you have permission to use, and offers a Cartoon filter. The default target is a cartoon face. To test: tap Start round, pick any tool, and throw at the moving face.
